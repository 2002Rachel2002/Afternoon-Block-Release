## Data

This project uses the [River Tyne fish counts](https://www.gov.uk/government/statistical-data-sets/river-tyne-fish-counts) dataset, published by the Environment Agency.

- **What it shows:** daily and monthly upstream counts of salmon and sea trout
- **Location:** the fish counter at Riding Mill on the main River Tyne
- **Formats:** ODS and Excel
- **Updates:** the Environment Agency aims to release new data monthly
- **Version used:** 02/11/2026
